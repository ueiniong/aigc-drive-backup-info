隐私政策

更新日期：2026年10月18日

AIGC云盘备份是所有者使用 rclone 访问本人 Google Drive 的个人备份配置，不面向其他用户提供服务。

访问与用途

rclone 根据所有者授予的 OAuth 权限与执行的命令，访问文件内容及名称、大小、修改时间等元数据，用于文件备份、恢复和管理。具体权限以 Google 授权页面为准。

存储与传输

文件在所有者指定的运行设备、存储位置与 Google Drive 之间传输。OAuth 令牌由运行 rclone 的环境按其配置保存。设备上的文件、缓存、日志和配置由所有者管理。本介绍网站不接收或保存这些文件及令牌。

数据共享与使用限制

此个人备份配置不以出售 Google 用户数据、广告定向或训练通用人工智能模型为目的。Google 用户数据仅用于上述个人备份与管理用途，并遵守 Google API Services User Data Policy，包括 Limited Use 要求。Google Drive 和网页托管服务各自按其适用政策处理服务数据。

撤销与删除

所有者可在 Google 账号的第三方连接设置撤销应用授权，并从运行环境删除 rclone 配置、令牌、缓存及日志。备份文件需在对应存储位置单独删除；撤销授权不会自动删除备份。

联系

这是单一所有者自用配置。如需联系，可通过对应 GitHub 仓库的 Issues 提交不含个人文件、密钥或令牌的问题。
